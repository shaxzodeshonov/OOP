# C++ OOP Mastery

An interactive course for people who are stuck on C++ object-oriented programming.

**Live: [collegeoop.vercel.app](https://collegeoop.vercel.app)**, you don't have to do anything distracting. Like you can just open this and start preparing for Mid-term. 

I built this while revising OOP for myself. Reading slides a third time wasn't working, so I rebuilt the whole syllabus as something I could click through, get quizzed on, and fail fast at. Then a friend of mine hit the same wall — understood the words `inheritance` and `virtual` but couldn't write a class from a blank file. so I cleaned it up and put it online.

If that's you, this is for you.
